
# 🐍 Snake Game

A fun, modern Snake Game built using **HTML, CSS, and JavaScript**. Control the snake, collect food, increase your score, and try to beat your high score!

## 🎮 Features

- 🐍 Smooth snake movement
- 🍎 Random food generation
- 🎯 Score tracking
- 🏆 High-score tracking
- ⏸️ Pause and resume functionality
- 🔄 Restart game option
- 💀 Game Over detection
- 📱 Responsive design for different screen sizes
- ✨ Modern arcade-style user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas
- Git and GitHub

## 🚀 How to Run the Game

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/snake-game.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Click Start and enjoy the game!

## 🎮 Controls

| Key | Action |
|---|---|
| ⬆️ Arrow Up | Move Up |
| ⬇️ Arrow Down | Move Down |
| ⬅️ Arrow Left | Move Left |
| ➡️ Arrow Right | Move Right |
| W, A, S, D | Alternative movement controls |
